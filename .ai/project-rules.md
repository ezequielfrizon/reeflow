# REEFLOW Project Rules

O ESP32 é soberano.

Nenhuma automação crítica pode depender da cloud.

Nenhuma automação crítica pode depender do app.

Toda implementação deve respeitar:

- architecture/*
- specs/*
- development-roadmap.md

Nunca inventar funcionalidades não especificadas.

Nunca alterar pinout.

Nunca alterar arquitetura sem aprovação.

Sempre implementar uma fase por vez.

Sempre consultar system-state-spec.md.
